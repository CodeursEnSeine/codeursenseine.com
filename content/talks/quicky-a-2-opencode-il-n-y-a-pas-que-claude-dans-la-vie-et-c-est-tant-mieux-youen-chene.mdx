Dans la vague d’innovation autour de la génération de code via les LLM, un même schéma se répète : tout le monde choisit la même solution sans se poser de questions, pour être sûr d’avoir le meilleur. Comme IBM dans les années 80, Oracle dans les 2000, AWS dans les 2010.

Ouvrez vos chakras et découvrez l’écosystème d’**OpenCode**, un harnais de code où le choix est roi !

La présentation sera moitié slides, moitié démo. Pour les plus nostalgiques, il y aura même du **C64 et de l’assembleur**.
