Vous êtes comme moi ? Vous voulez automatiser une tâche rapide avec un script simple, mais à chaque fois que vous commencez, impossible de vous rappeler la syntaxe exacte du Bash ou du Python. Vous vous surprenez à rêver de pouvoir simplement l'écrire en Java.

Attendez une seconde : c'est désormais tout à fait possible.

Dans ce talk, nous explorerons comment Java a évolué pour devenir un outil d'automatisation pratique. Grâce au support du shebang, au single-source file execution et aux instance main methods, nous verrons comment Java est devenu un langage de scripting léger et efficace. Nous irons plus loin en découvrant JBang pour les cas d'usage plus avancés et la gestion des dépendances.

À travers des démos en direct, vous apprendrez comment le Java moderne vous permet d'automatiser rapidement vos tâches et d'écrire des scripts à la fois puissants et maintenables. Vous n'aurez plus besoin de vibe coder votre prochain script en Bash !
